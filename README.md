# CRAVE.

A modern, interactive web application designed to simplify meal preparation with dynamic recipe scaling and smart pantry management. 

## 🚀 Current Status: Frontend Prototype
This project is currently in active development. The static frontend architecture is complete, featuring a high-performance UI. The backend data layer (Node/Express/MongoDB) is currently being integrated.

## ✨ Features (Implemented)
* **Modern UI/UX:** Responsive landing page built with Tailwind CSS v4 utilizing a custom off-white and vibrant orange culinary theme.
* **Physics-Based Animations:** Infinite seamless recipe carousel, optical illusion and SVG masking driven by Framer Motion.
* **Modular Architecture:** Clean React functional components isolating layout, physics, and typography (Navbar, HeroSection, TrendingFeed).

## 🗺️ Roadmap (Upcoming Backend)
* **RESTful API:** Express routes for fetching trending recipes and executing search queries.
* **Database Integration:** MongoDB Atlas connection enforcing strict Mongoose data schemas.
* **Smart Search:** Optimized MongoDB text indexing for real-time ingredient and recipe filtering.
* **Dynamic Scaling Engine:** Core algorithm to adjust serving sizes and ingredient proportions on the fly.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Tailwind CSS v4, Framer Motion, Lucide Icons
* **Backend (WIP):** Node.js, Express.js, MongoDB, Mongoose
